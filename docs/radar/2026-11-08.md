# Radar: 2026-11-08

What the field shipped from 2026-10-18 to 2026-11-08, and what it means for Girth.

**How it was swept:**
- Five parallel passes: labs (every property), papers, repos/OSS, influencers/communities/newsletters, and news/eng blogs/products.
- **Tools:**
  - Scrapling `extract get` works for static pages.
  - Scrapling `extract fetch --headless` works on Reddit's `/top/?t=week`, reading the `<shreddit-post>` attributes.
  - The HN Algolia API works, with `>` sent as `%3E`.
  - **X failed by every route:** Obscura, xcancel, nitter and syndication.
- Items marked *(vendor)* or *(unverified)* are claims we did not check.

## The themes

1. **Prompt-cache hygiene is the biggest published saving.**
   - Cloudflare's code review went from $2.43 to $0.77 per review. One shared breakpoint took cache hits from 14–26% to 91–99% ([blog](https://blog.cloudflare.com), 10-19).
   - Datadog listed six causes of cache misses, including a volatile prefix, tool order, a missing `cache_control` and OpenAI-compatible endpoints (11-06).
   - CACHELINT (arXiv 2610.34817) found silent cache bugs in 32 of 571 agent repos.
   - Trimming has a cost too: keeping only the last 5 tool outputs cut prompt tokens by 33%, but raised uncached prefill by 608% (arXiv 2610.34763).
2. **Hidden harness overhead.**
   - **Claude Code's `agent_summary` timer** re-sends background-agent transcripts to Opus about every 30 s, which is 16–26% of spend. It appears as `query_source=agent_summary` in OTel.
     - `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES=1` turns it off *(unverified, ≥ 2.1.318)*.
   - Claude Code's Bash tool description is about 3k tokens.
   - OpenCode 2.2's session warming spends tokens.
   - OpenAI's Agents API now compacts in the background by default and "may increase token usage".
3. **Routing up only when needed.**
   - Hightouch's small model escalates to Opus only when unsure, at 1.8–4.4× lower cost (11-04).
   - Copilot Fusion GA claims half the cost per task *(vendor)*.
   - OpenRouter Auto Code avoids switching models mid-session so the cache survives.
   - Kiro Auto keeps 80% of tasks on the cheap model.
   - "Pairing Matters" (2610.32131) found tokens per resolved task vary more than 20× across harnesses for the same model.
4. **Plans became pooled token allowances.**
   - ChatGPT and Codex limits merge in December.
   - Plans include API credits equal to their price (OpenAI and Anthropic).
   - Max became Ultra: no 5-hour cap, but a weekly cap.
   - What users can't see is the share of plan used per task.
5. **Cost per task, not price per token**, is the metric Google's developer blog argues for (11-03). Ramp: spend is flat while usage climbs.
6. **Competitors moved toward Girth's whole-stack lane.**
   - JetBrains Air Governance is GA ($20 per developer, cross-vendor, hard limits).
   - Langfuse AI Gateway and Skill Management launched (11-03/04).
   - RTK v1.1 now has `rtk-proxy` (compression, routing, cache alignment, BUSL) and RTK Pro.
   - ccusage was rewritten in Rust and reads four harnesses.
   - tokscale reads DeepSeek Harness, Cursor and OpenCode v2.
   - Switch Agents tracks Claude Code and Codex spend.
