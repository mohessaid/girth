## Skills: the thesis under test
- **Doubt is loud.** Dubach's "I Just Deleted All My Agent Skills" cites these figures:
  - 92 of 98 public skills had no measurable effect.
  - Web-dev skills cost 72–394% more tokens.
  - About 25% of skills have a vulnerability.
  - Curated skills still lift pass rates from 33.9% to 50.5%.
- Ask HN: "How do you evaluate your agents' skills?"
- **Papers:**
  - 2611.12953: skills and multi-agent setups cost 1.4–4.7× the tokens for small gains, and degraded skills fall below having no skill at all.
  - 2611.13144 (Student-Aware Teaching): a teacher model writes skills for a student model's diagnosed failures, and admits one only if its mean pass-rate gain over an empty library is positive on 1–4 matched dev tasks, one run each. The whole system reached 86.5% against 75.0% untaught; a teacher with the same gate but no learner model reached 81.0%, so the gate's own share isn't isolated. Under misleading learner profiles none of 48 candidates passed admission. With a fixed library, acceptance still ranged 71.7–82.5% between runs, which is the noise a small gate faces.
  - 2611.12041: compiling 232 skills into 95 shared bricks cut their tokens by 59% and raised the score from 0.638 to 0.748.
  - 2611.12155 StealthyPoison: poisoned skill metadata ranks first 13.6% more often across 26K registry entries, and most payloads evade SkillSpector. A companion paper raises detection F1 from 0.70 to 0.85 by adding sandbox evidence.
- **More skill repos:** Jane Street's `agent_skills`; Chrome, Edge, Firefox and MDN's `modern-web-guidance`; `cloudflare/security-audit-skill` (+10.7k this week); `google/skills`; `addyosmani/agent-skills`.

## Cost signals
- **Plan limits:** Fable 5.2 burns them fast ("I said 'H' and it used 26% of daily usage"). Pro gets Fable credits from Nov 17 *(unverified)*.
- **Subagent cost:** Claude Code 2.1.323 removed `subagentStatusLine` (issue #109446), so per-subagent cost is no longer visible. Girth's mod already prices subagent turns.
- **MCP overhead:** GitHub's MCP server adds 19.4k tokens to every request. One task cost 59k tokens via MCP, 1.4k via CLI and 3.3k via a skill (OpenRouter, in TLDR AI).
- **Model switches:** switching models mid-session drops prefix-cache hits from 80–89% to 44–65% (2611.13176).
- **Unused tool output:** agents use 27% of the tool-output tokens they receive, and cache reads are 13–73% of total cost (2611.12122).
- **Decision models:** Amazon's Strands Decider was about 98% cheaper on labelling. Gemini Decisions costs $0.10 input with free output.
