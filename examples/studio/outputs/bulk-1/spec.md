# Spec — "6 steps, one video"

## Format
- 1080×1350 (4:5 portrait), 30 fps, no audio, MP4 (draft quality)

## Length
- 9 s total = 6 panels × 1.5 s, no gaps, no overlap

## Beats
1. 0.0–1.5 s Reference lit → spec.md
2. 1.5–3.0 s Data lit → data.json
3. 3.0–4.5 s Story lit → story.md
4. 4.5–6.0 s Motion lit → index.html
5. 6.0–7.5 s Direct lit → timing.json
6. 7.5–9.0 s Ship lit → final.mp4

## Style
- Dark ink background, six equal vertical panels side by side with labels
- One accent colour marks the lit panel; the others stay dim
- Output filename appears in monospace under the lit panel only
- Title "6 steps, one video" on top; system sans-serif / monospace, no external assets
- Only numbers on screen are those in data.json
