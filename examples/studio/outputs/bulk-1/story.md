# Story

**Point:** a video is six small steps, and each one leaves a file behind.

1. **Setup (Reference → Data):** brief and numbers are written down first (spec.md, data.json).
2. **Build (Story → Motion):** the point and beats, then the animation itself (story.md, index.html).
3. **Finish (Direct → Ship):** timings are pinned, then the render ships (timing.json, final.mp4).
