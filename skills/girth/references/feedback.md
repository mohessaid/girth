# Rate a crafted skill

1. Ask with AskUserQuestion: "How did `girth-<domain>` do?" The options are **Helpful** and **Not helpful**.
2. Optionally ask: "Anything to add? It stays on your machine." Don't press if they skip it.
3. Run `scripts/girth feedback girth-<domain> up` (or `down`), adding `--note "<their words>"` if they gave one.
4. Confirm in one line. If it was not helpful, offer a review (`references/review.md`).
